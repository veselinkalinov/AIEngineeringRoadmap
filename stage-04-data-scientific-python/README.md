# Stage 04 — Data & Scientific Python

> Before you can build models, you need to understand the data that feeds them.
> NumPy, Pandas, and Matplotlib are the foundation of every ML pipeline.
> Learn them properly here — you'll use them in every stage that follows.

---

## Resources

**[NumPy — Official Documentation & Tutorials](https://numpy.org/learn/)**
Start with the NumPy quickstart guide, then work through the fundamentals: array creation, indexing, slicing, broadcasting, vectorized operations, and linear algebra operations. W3Schools NumPy is a useful parallel reference for quick syntax lookup.

**[W3Schools — NumPy Tutorial](https://www.w3schools.com/python/numpy)**
Supplementary reference. Use alongside the official docs for syntax confirmation and quick examples.

**[Pandas — Official Getting Started Guide](https://pandas.pydata.org/docs/getting_started/index.html)**
Series, DataFrames, indexing, groupby, merge, apply, handling missing data, reading/writing CSV and JSON. Follow the official 10-minute tutorial first, then work through the user guide section by section.

**[W3Schools — Pandas Tutorial](https://www.w3schools.com/python/pandas)**
Supplementary reference for Pandas syntax.

**[Matplotlib — Official Tutorials](https://matplotlib.org/stable/tutorials/index.html)**
Line plots, scatter plots, bar charts, histograms, subplots, styling. Visualization is how you debug data. Learn it here — you'll use it constantly in Stage 05.

**[SciPy — Official Tutorial](https://docs.scipy.org/doc/scipy/tutorial/index.html)**
Statistical distributions, optimization, signal processing, linear algebra extensions. Work through the core modules: `scipy.stats`, `scipy.optimize`, `scipy.linalg`.

**[AI Data Scientist Roadmap — roadmap.sh](https://roadmap.sh/ai-data-scientist)**
Open this at the start of the stage and read the Machine Learning section (read only — you'll implement it in Stage 05). Use it as a map of what's coming.

---

## What You'll Be Able to Do After This Stage

- Manipulate multi-dimensional arrays with NumPy (broadcasting, vectorized ops, linear algebra)
- Load, clean, transform, and analyze structured data with Pandas
- Visualize data distributions, correlations, and trends with Matplotlib
- Apply basic statistical functions with SciPy
- Build end-to-end data analysis pipelines from raw CSV to insight
