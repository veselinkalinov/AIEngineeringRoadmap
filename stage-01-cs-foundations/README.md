# Stage 01 — CS Foundations

> You can't engineer what you don't understand.
> Before writing a single line of AI code, you need to know how computers actually work —
> memory, execution, abstraction, problem decomposition.
> CS50x is the best entry point that exists. Use it.

---

## Resources

**[CS50x — Introduction to Computer Science](https://cs50.harvard.edu/x)**
Harvard's flagship CS course. Free. Covers computational thinking, abstraction, algorithms, data structures, memory, and multiple languages. Weeks 0–6 are the foundation — work through them in sequence. The problem sets are mandatory; passive watching doesn't count.

**[Computer Science Roadmap — roadmap.sh](https://roadmap.sh/computer-science)**
Use this as a parallel reference map. At the start of the stage, open it and scan every node. At the end, return and audit yourself: which nodes can you explain without looking them up? This is your gap detector, not a syllabus.

**[Git & GitHub Roadmap — roadmap.sh](https://roadmap.sh/git-github)**
Version control is a non-negotiable engineering skill. Read through this roadmap systematically — VCS concepts, Git internals, branching strategies, GitHub workflows. Every project from this point forward lives in a repository.

---

## What You'll Be Able to Do After This Stage

- Explain how a computer executes a program (compilation, memory, pointers)
- Implement basic algorithms (search, sort) from scratch
- Use Git for version control on every project you build
- Navigate and contribute to a GitHub repository
- Decompose a problem into functions and modules
