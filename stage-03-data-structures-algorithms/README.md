# Stage 03 — Data Structures & Algorithms

## Current Status

The dedicated DSA curriculum is no longer active. Existing Boot.dev, Codédex, CS50, and Educative material remains here as historical work and reference. New practice is self-directed through LeetCode under `leetcode/`; there is no required linear checklist or additional DSA course sequence.

> Every system that scales does so because the person who built it understood
> how data moves through memory and how algorithms behave at scale.
> You don't need to memorize interview puzzles. You need to understand the fundamentals.

---

## Resources

**[Boot.dev — Learn Data Structures and Algorithms](https://www.boot.dev)**
Interactive, code-focused DSA course. Covers arrays, linked lists, trees, graphs, hash maps, heaps — and the algorithms that operate on them. Part 1 covers core structures; Part 2 covers sorting and graph algorithms. Complete both.

**[Educative — Data Structures and Algorithms for Coding Interviews](https://www.educative.io)**
Text-based course with in-browser code execution. Covers the same material from a different angle — useful for reinforcing understanding after Boot.dev. Focus on the pattern-recognition sections: sliding window, two pointers, BFS/DFS, dynamic programming.

---

## Core Concepts Checklist

Work through these in order. Implement each from scratch in Python before moving on:

- [ ] Arrays and dynamic arrays
- [ ] Linked lists (singly, doubly)
- [ ] Stacks and queues
- [ ] Hash maps and hash sets
- [ ] Trees (BST, traversals: inorder, preorder, postorder)
- [ ] Graphs (adjacency list/matrix, BFS, DFS)
- [ ] Heaps / priority queues
- [ ] Sorting (bubble, merge, quick — understand complexity of each)
- [ ] Binary search
- [ ] Big-O analysis for all of the above

---

## What You'll Be Able to Do After This Stage

- Implement core data structures from scratch in Python
- Analyze time and space complexity of algorithms
- Select the right data structure for a given problem
- Recognize algorithmic patterns (sliding window, BFS, DFS, divide and conquer)

---

## Project Milestone

Implement a working graph with BFS and DFS from scratch. Write tests that verify correctness on at least 5 different graph configurations.
