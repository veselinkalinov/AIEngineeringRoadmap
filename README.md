## How to use this

Start at Stage 01. Each stage has a primary resource to follow linearly and supplementary material for depth.

This roadmap is opinionated by design. Every resource was chosen for a specific reason and placed in a specific sequence. The goal isn't to collect completions — it's to build the mental model of an AI engineer, layer by layer.

Use [roadmap.sh](https://roadmap.sh) as your parallel reference map throughout each phase. At the end of each stage, return to the relevant roadmap and audit yourself.
