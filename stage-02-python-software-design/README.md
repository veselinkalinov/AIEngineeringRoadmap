## Resources

**[CS50P — Introduction to Programming with Python](https://cs50.harvard.edu/python)**
Harvard's dedicated Python course. Covers functions, libraries, OOP, file I/O, regular expressions, and testing. Work through Weeks 0–9 in order. Complete every problem set — they're designed to build real programming judgment, not just syntax recall.

**[ArjanCodes — Software Design in Python](https://www.youtube.com/playlist?list=PLC0nd42SBTaNuP4iB4L6SJlMaHE71FG6N)**
This is what separates engineers from hobbyists. Covers value objects, dataclasses, protocols, abstract base classes, dependency injection, and clean architecture patterns in Python. Watch this after CS50P — you need to know the language before you refactor it.

**[Codedex Python Courses](https://www.codedex.io)**
Supplementary interactive exercises. Use for drilling specific syntax and building muscle memory alongside the main courses.

## What You'll Be Able to Do After This Stage

- Write Python programs using OOP, modules, file I/O, and error handling
- Apply software design principles: SOLID, composition over inheritance, dependency injection
- Structure a Python project with clean separation of concerns
- Write tests for your code
- Read and understand production-grade Python codebases

---

## Project Milestone

Build a CLI tool of your choosing (contact manager, task tracker, file organizer) that:
- Uses at least 3 classes with clear responsibilities
- Reads and writes to persistent storage (file or SQLite)
- Has basic error handling and input validation
- Is version-controlled in a Git repository
